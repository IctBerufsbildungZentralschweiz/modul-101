# Drucklayout (Print)

Mittels der [@media-Query](../05-responsive-design/media-queries.md#medien-typen) kann festgestellt werden, ob die Webseite gerade ausgedruckt wird. Entsprechend können in CSS für den Druck andere Formatierungen überschrieben werden.

**Aufgabe:**&#x20;

1. Überlege, welche Inhalte auf Papier interessant sind und welche nicht. Typscherweise wird beim Drucken die Navigation und ev. auch Elemente aus Header oder Footer weggelassen.&#x20;
2. Erstelle in deinem bestehenden CSS eine Druckversion, für die du einzelne Elemente für den Druck ausblendest.&#x20;
