# Icons (FontAwesome)

Auf Websites werden häufig Icons eingesetzt. Woher bekommst du gute Icons? \
Du kannst eigene Icons als Bild einfügen (z.B. als SVG). Eine andere Möglichkeit ist, die Icons von [FontAwesome.com](https://fontawesome.com/search#icongrid) zu nutzen. Manche Icons sind umsonst, andere kosten.&#x20;

**Aufgabe:**&#x20;

Schau dir die riesige Icon-Sammlung an und füge ein paar in deine Website ein. Z.B. Social-Icons im Footer oder einen Burger für die Mobile Navigation oder ein paar nach deiner Wahl.&#x20;
