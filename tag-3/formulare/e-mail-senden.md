# E-Mail senden

Eine sehr einfache Möglichkeit der Zweiweg-Kommunikation mit Website-Besuchern ist, dass Besuchende eine E-Mail schicken können. Dazu braucht es nur einen Link mit `mailto:`, dann eine Mailadresse. Ein Klick auf den Link öffnet das lokale Mail-Programm:&#x20;

```html
<a href="mailto:muster@beispiel.com">E-Mail schreiben</a>
```

Optional können weitere Informationen definiert werden, z.B. ein Betreff "Anfrage" für die E-Mail (`?subject=Anfrage`):&#x20;

```html
<a href="mailto:muster@beispiel.com?subject=Anfrage">Anfrage stellen</a>
```

### 🛠️ Aufgabe

Füge in deine Seite "Über mich" (`about-me.html`) einen Link "E-Mail senden" ein und hinterlege deine Mailadresse. Teste den Link.&#x20;
