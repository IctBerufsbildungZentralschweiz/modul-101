# 🛠️ Aufgabe Grid mit Navigation

Füge in dein Grid der letzten Aufgabe nun die Navigation ein, welche du in der Flexbox-Aufgabe erstellt hast:&#x20;

<figure><img src="../../../.gitbook/assets/image (2) (1).png" alt=""><figcaption></figcaption></figure>

**Zusatzaufgaben:**

1. Definiere für den Header ein zufälliges Hintergrundbild. \
   Nutze dazu Bilder von [picsum.photos](https://picsum.photos/) mit einer sinnvollen Auflösung (z.B. 1400px x 200px).&#x20;
2. Füge in den Inhalt eine Überschrift und etwas Beispiel-Text ein. \
   Dazu kannst du den [blindtextgenerator.de](https://www.blindtextgenerator.de/) benutzen.
