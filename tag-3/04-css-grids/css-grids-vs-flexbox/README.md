# Grids vs. Flexbox

## Wann soll ich Grids nutzen, wann Flexboxen?&#x20;

Eine klare Antwort gibt es nicht immer. In vielen Anwendungsfällen lassen sich beide verwenden. Der Aufwand und die Codemenge können sich jedoch deutlich unterscheiden.&#x20;

Folgende Fakten können dir aber bei der Entscheidung helfen:

* **Flexbox** ist primär für das Platzieren einer variablen Zahl von **Elementen in einer Dimension** konzipiert, horizontal oder vertikal (Beispiel: Navigation). Flexbox ermöglicht leicht die Kontrolle über die Reihenfolge von Elementen.
* **Grids** sind für das Platzieren von **Elementen in zwei Dimensionen** konzipiert (Beispiel: Basislayout, Bildergalerien). Grids eignen sich deshalb für die Umsetzung komplexer Layouts. Das HTML Markup und der CSS Code werden deutlich übersichtlicher sein.
* **Responsive Layout**: Grids benötigen sehr wenig Code, wenn es darum geht, eine Website responsive zu machen. Bei Flexbox müssen meistens mehr Eigenschaften für unterschiedliche Bildschirmgrössen überschrieben werden.
* Ausgefallene Layouts lassen sich mit Grids einfacher umsetzen als mit Flexbox (siehe z.B. [https://codepen.io/editor/sternenvogel/pen/01a18957-d6de-77dd-aab1-09470b0a6b56](https://codepen.io/editor/sternenvogel/pen/01a18957-d6de-77dd-aab1-09470b0a6b56)).
