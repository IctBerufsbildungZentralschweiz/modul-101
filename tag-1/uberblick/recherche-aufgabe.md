# 🛠️ Recherche-Aufgabe

Bildet Gruppen und wählt eine der folgenden Websites für eure Detektivarbeit aus:&#x20;

* [ICT-Berufsbildung](https://www.ict-berufsbildung.ch/grundbildung/ict-lehren/mediamatiker-in-efz) (Mediamatiker/in EFZ)
* [VAUDE](https://www.vaude.com/) (Outdoor-Ausrüstung)
* [W3C](https://www.w3.org/) (World Wide Web Consortium)
* [HC Kriens-Luzern](https://hckriens-luzern.ch/) (Handball-Club)

Nutzt die Entwickler-Tools eures Browsers und findet Beispiele, wie folgendes umgesetzt wurde:&#x20;

* 5 Struktur-Elemente: Welche HTML-Tags wurden verwendet?
* 5 Darstellungs-Aspekte (Farben, Schrift, Schatten, Anordnung etc.): Mit welcher CSS-Deklaration (Eigenschaft & Wert) wurde es erreicht?&#x20;
* 2 Inhaltselemente (Überschriften, Text & Bilder): Wie wurde die Überschrift definiert? Warum wurde dieses Bildformat gewählt?&#x20;
* 1-2 Effekte oder Interaktionen: Nur grob, wo findest du sie im Code?&#x20;

Stellt eure Erkenntnisse vor.&#x20;

{% hint style="info" %}
**Entwicklertools öffnen**

* In fast allen Browsern mit Rechtsklick + "Untersuchen"

Oder:&#x20;

* Windows (Firefox + Chrome): F12
* Mac (Firefox + Chrome): Cmd + Option (Alt) + I
* Safari: Das Entwicklermenü muss oft erst aktiviert werden: \
  Einstellungen > Erweitert > "Funktionen für Webentwickler anzeigen".\
  Danach: Cmd + Option (Alt) + C \
  (oder über das Menü "Entwickler > Web-Inspektor einblenden")
{% endhint %}
