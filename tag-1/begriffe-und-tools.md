# Begriffe und Tools

## Begriffe

Einige Begriffe sollten auseinandergehalten werden:

* **Internet:** Ein Netz von dezentral vernetzten Geräten, über welche viele Dienste laufen wie E-Mail, Video-Calls, Messenger, WWW, Streaming, Internet-Telefonie, Filetransfer etc.
* **Web / WWW:** Weltweit mit Hyperlinks vernetzte HTML-Dokumente, die über das Protokoll HTTP/HTTPS übertragen werden.
* **Website**: Gesamtheit aller Seiten, welche zu einem Webauftritt gehören
* **Webseite**: Eine einzelne Seite innerhalb eines Webauftrittes
* **Homepage**: Startseite einer Website (Home)

## Tools

**Entwicklungsumgebung für HTML & CSS:**\
Im Prinzip wird nur ein Texteditor benötigt, z.B. [Notepad++](https://notepad-plus-plus.org/downloads/).\
Hilfreicher ist aber eine Entwicklungsumgebung wie [Visual Studio Code](https://code.visualstudio.com/download).\
Empfohlene Extensions für VS Code: "HTML CSS Support" von ecmel, "Live Server" von Ritwick Dey oder von Yannick, "open in browser" von TechER.

**Bildbearbeitung:** Eine Software wie [Photoshop](https://www.adobe.com/ch_de/products/photoshop.html), [Gimp](https://www.gimp.org/downloads/) oder [IrfanView](https://www.irfanview.com/main_what_is_ger.htm) oder ein Online-Dienst wie [Online Image Editor](https://www.online-image-editor.com/) oder [Bulk Resize Photos](https://bulkresizephotos.com/).

**Kompatibilität:** [caniuse.com](https://caniuse.com/) sagt dir, von welchen Browsern ein Feature unterstützt wird und wie verbreitet diese Browser aktuell sind.

**Validierung:** [HTML-Validator](https://validator.w3.org/) und [CSS-Validator](https://jigsaw.w3.org/css-validator/)

**Testen und Fehlersuche:** \
Dein Browser bietet dir umfangreiche **Entwicklertools**. \
Mit Rechts-Klick & "Untersuchen" auf ein Element einer Website oder die Taste `F12` öffnen sich die Entwickler-Tools. \
Bei **Safari** müssen die Entwicklertools ev. zuerst frei geschaltet werden: \
Safari > Einstellungen > Erweitert > „Funktionen für Webentwickler anzeigen“.

**Veröffentlichung:** FTP-Tools wie [WinSCP](https://winscp.net/eng/download.php) oder [FileZilla](https://filezilla-project.org/).
