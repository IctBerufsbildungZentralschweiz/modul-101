# 🛠️ Aufgabe Navigation mit Media-Queries

Passe die "Aufgabe Navigation" wie folgt an:

1. Erstelle eine Mobile-Version:
   * Mache den Header auf Desktops 250px hoch, auf Tablets 200px (width < 1200px) und auf Handys 150px (width < 768px).
   * Ordne die Menü-Optionen für Handys untereinander an statt nebeneinander. Finde im Browser heraus, wo ein Break-Point für den Wechsel zwischen Mobile & Desktop sinnvoll ist.
   * Mach die Überschrift 1 etwas kleiner auf Handys.
2. Teste auf deinem Handy:
   * Öffne dein FTP-Tool (WinSCP oder FileZilla), verbinde mit dem Server und erstelle in deinem persönlichen Ordner ein neues Unterverzeichnis `/navigation`
   * Lade deine Übung (`html` und `css`) hoch und teste sie auf deinem Handy.&#x20;
3. Erstelle eine Druckversion (optional):
   * Blende die gesamte Navigation beim Ausdrucken aus.
   * Entferne in allen Teilen den Hintergrund und mach die Text-Farbe schwarz.
