# 🛠️ Aufgabe Navigation mit Media-Queries

Passe die "Aufgabe Navigation" wie folgt an:&#x20;

1. Erstelle eine Mobile-Version:&#x20;
   * Mache den Header auf Desktops 250px hoch, auf Tablets 200px (width < 1200px) und auf Handys 150px (width < 768px).&#x20;
   * Ordne die Menü-Optionen für Handys untereinander an statt nebeneinander. Finde im Browser heraus, wo ein Break-Point für den Wechsel zwischen Mobile & Desktop sinnvoll ist.&#x20;
   * Mach die Überschrift 1 etwas kleiner auf Handys.
2. Erstelle eine Druckversion:&#x20;
   * Blende die gesamte Navigation beim Ausdrucken aus.&#x20;
   * Entferne in allen Teilen den Hintergrund und mach die Text-Farbe schwarz.&#x20;
