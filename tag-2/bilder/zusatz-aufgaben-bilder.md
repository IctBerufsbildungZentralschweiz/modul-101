# 🛠️ Zusatz-Aufgaben Bilder

1. Erstelle eine neue HTML-Datei `media.html` mit dem bekannten [HTML-Grundgerüst](../../tag-1/html/html-dokument.md).
2. Erstelle darin ein `<main>`-Element mit einer Überschrift 1 und drei `<article>`-Elementen. Diese Elemente sollen jeweils eine Überschrift 2 enthalten ("Bilder", "Videos", "Audios").
3. Probiere darin die beschriebenen Medien-Elemente aus:
   * Bilder einbinden, inkl. Lazy-Loading
   * Responsive Bilder: Teste `<picture>` mit WebP- und JPEG-Versionen
4. Zusatzaufgaben für schnelle Lernende:
   * Erstelle eine Galerie mit Bildbreite 33%. Schau im Internet nach, wie sie automatisch sinnvoll nebeneinander / untereinander angeordnet werden können.
